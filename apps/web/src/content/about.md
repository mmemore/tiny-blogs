这个站是一个自己写的个人博客：没有第三方托管、没有主题市场，前台、后台、数据库、发布流程都是从头写了一遍。

为什么自己写。现成的博客平台能解决九成的事，但剩下那一成——构建期预渲染、中文全文检索的分词配置、编辑时的乐观锁——恰恰是想弄明白的那部分。*把东西真的发到线上去*，比把一份教程跑通更有用。

技术上分三层。前台是 Vue 3 + TypeScript + Vite，构建期渲染成静态 HTML，读者拿到的第一屏不依赖 JavaScript 执行；API 是 NestJS + TypeORM，负责鉴权、写作与公开读侧；数据落在 MySQL 8，中文检索用 ngram 解析器，不需要额外的搜索引擎。

写作原则只有两条：*写清楚为什么*，以及只写自己能复现的东西。踩过的坑记下来，下次就不必再踩一遍。

站名 tiny-blogs 不是谦辞，是范围声明：这里只写小东西。

# 09: 后台——编辑器与图片上传

**What to build:** 作者的核心工作台：双栏 Markdown 编辑器（实时预览与线上同一渲染管线）、保存草稿与发布、冲突提示，以及粘贴/拖拽即上传的图片链路（后端 Storage 模块一并交付）。全项目最大的一张票。

**Blocked by:** 08 后台——登录与管理列表

**Status:** ready-for-agent

- [x] 双栏编辑 + 实时预览：预览与前台/预渲染共用 shared 的同一渲染实现
- [x] 元数据编辑：标题、slug、摘要、标签（回车添加）
- [x] 保存草稿与发布两个动作；⌘S / ⌘Enter 快捷键；有未保存改动时离开页面提示
- [x] 冲突提示：另一窗口更新后本窗口保存返回 409，界面明确提示而不是静默覆盖
- [x] 图片链路：粘贴/拖拽上传 → `POST /api/admin/upload`（按内容 hash 命名、mime 白名单、5MB 上限）→ URL 自动插入正文
- [x] Storage 两个适配器（本地卷 + 内存）均有测试；上传文件不入 git
- [x] 发布动作的界面文案说明"发布后需触发全量重建才上线"（与票 10 的链路衔接）

# 07: 前台内容页

**What to build:** 访客实际花时间的地方：文章详情的完整阅读体验（排版、代码高亮、目录、上下篇）、标签/归档/关于，以及 404。至此前台全部路由在 SPA 模式下可用。

**Blocked by:** 06 前台基础——令牌与壳层

**Status:** ready-for-agent

- [ ] 文章详情：正文排版（标题层级、代码块高亮、引用、列表、表格）、目录锚点与滚动跟随、阅读时长、上一篇/下一篇
- [ ] meta 完整：`<title>`、`<meta name="description">`、OG 标签取 summary，与预渲染产物一致
- [ ] 标签筛选页、标签总览（含计数）、归档页（年月聚合，展示为"年鉴"）
- [ ] 关于页内容来自仓库内的本地 Markdown，不占表、不占接口
- [ ] 404 页与未知 slug 的兜底路由
- [ ] Giscus 占位组件：配置项为空则整块不渲染
- [ ] 移动端断点下全部页面可读

# 04: 文章写侧闭环

**What to build:** 后台写作的核心后端行为：从 curl 建草稿、发布、更新到删除的完整闭环，含编号永不位移的发布语义与防覆盖/防越权的错误模式。这张票交付后，"写"这条线在接口层就是完整的。

**Blocked by:** 02 Schema、迁移与种子管理员；03 鉴权闭环

**Status:** ready-for-agent

- [ ] 创建草稿：`author_id` 自动取当前登录用户；slug 唯一冲突返回 409
- [ ] 发布：首次分配 `published_seq`（当前最大值 +1）并写 `published_at`；重复发布幂等；取消发布再发布编号不变
- [ ] 更新：`expectedUpdatedAt` 不匹配返回 409（双开标签页互不覆盖）
- [ ] 归属校验：用第二个用户 fixture 修改/删除他人文章返回 403（v1 单管理员也要实现并测试）
- [ ] 删除为硬删，草稿与已发布均可删
- [ ] 参数校验失败返回 422，错误体为统一信封 `{ error: { code, message } }`
